# Demo walkthrough

1. Open the assessment. Show the language switch, six sections, and browser draft recovery.
2. Change a technical skill to a fractional value such as 3.5. Optionally enter its last-used date.
3. Submit and compare the three career scores. Explain that the scores support exploration and are not employment probabilities.
4. Open a learning priority. Show the project idea, provider reference, and learn/build/reflect milestones.
5. Open the dashboard. A first assessment produces one observed point; a later saved assessment adds another real observation.
6. Show private access backup and restore controls without displaying a real access code in a recording.
7. Visit How it works and explain the model's measured limitations.

Suggested screenshots: desktop assessment, career results, dashboard, and narrow mobile assessment. Capture the actual running interface; use synthetic/demo data and exclude credentials or private records.

A short recording can follow steps 1–5 in roughly 90 seconds. Screenshots and video must be captured from a browser; none are simulated or presented as verified screenshots in this repository.

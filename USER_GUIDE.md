# Using Pathfinder

## Assessment

Work through the six sections. Starting ratings are examples: change them to reflect your experience. Technical skills accept decimal values; the other rating groups use a five-point scale. Optional last-used dates apply a heuristic recency adjustment.

The background confidence slider records your own reflection and does not influence the classifier. Your draft stays in this browser when local storage is available. You can revisit completed sections before submitting.

## Results and learning

Compare the top three suggested careers, skill averages, and learning priorities. Scores are exploratory model outputs, not career-success probabilities. Open a practice plan to see a project idea, a learning reference, and a checklist. Checklist progress stays on the current device and survives page reloads.

Download results as JSON for your own records. A failed server save does not erase your results; retrying uses the same assessment ID to avoid duplicates. You can also choose not to save to the server.

## Private dashboard

Saved history belongs to a private device access code. The dashboard shows observed skill levels from your real saved assessments. It never fills in invented earlier progress.

Download a private access backup before changing browsers. Keep it private: anyone with its profile ID and code can access that history. Restore access by entering those two values. Older local profiles may need the server owner to run the recovery script.

Starting a new private history disconnects this browser from the old profile without deleting its server records. Deleting saved data removes the server profile and clears the current browser's draft and learning checklist after confirmation. External backups are managed separately by the server owner.

## Language and accessibility

Switch between English and Spanish in the header. Native controls support keyboard navigation; focus indicators and reduced-motion preferences are supported. If storage is blocked, the assessment can still run, but saving drafts or private profile access may be unavailable.

## Interpreting the recommendations

The model uses synthetic data and twelve technology career labels. Release test accuracy is 45%, with 79% top-three accuracy on 100 synthetic records. It has not been validated against employment outcomes. Use the suggestions alongside projects, courses, and conversations with people working in the field.
